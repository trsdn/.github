Design and write a published site for this repository with the
`frontend-designer` agent, against the standard in the `trsdn/.github` checkout
at $1 (a local path; ask if not given).

1. Read the repository and the product it ships, in the order the agent's
   instructions give, until you can state what makes this project specific —
   not a generic description that would fit any similar tool.
2. Read the standard's Site Content Baseline and Site Design sections in the
   checkout at $1.
3. Design deliberately: colour, type, and layout that follow from what you
   read, explained briefly as you go.
4. Write the site into `docs/` or `site/` (match whatever the repository
   already uses, or `docs/` if neither exists — GitHub Pages serves it without
   further setup). Self-host every asset.
5. Cover the seven content items with real content. Check the landing order
   (what it is, who for, status) appears first in source.
6. Report what you built, why, and anything you were not sure about. Leave it
   in the working tree; do not commit or open a pull request yourself.
